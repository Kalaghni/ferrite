# FERRITE v0.8.1

## Updater fix

- Corrected the compiled version to match the release. The v0.8.0 archives were labelled 0.8.0 but contained executables identifying themselves as 0.7.0, so the launcher offered the same update after every restart.
- Restart the newly installed executable by its saved installation path, and keep the launcher open with an error if restarting fails.
- Remove updater test-version overrides during restart so a test launch cannot force a repeated update prompt.
- Check that release tags, workspace package versions and installer binaries agree before publishing or packaging.
- Added `--version` / `-V` to the client and dedicated server for checking the compiled version without opening a window or starting a server.

Players on v0.8.0 can use **UPDATE & RESTART** to install v0.8.1. The maps, models, skins and gameplay from v0.8.0 are unchanged.
