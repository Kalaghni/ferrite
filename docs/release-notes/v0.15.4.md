# FERRITE v0.15.4

A macOS app on a disk image, and a lobby chat that stays in its box.

## Changes

- **FERRITE for macOS as an app.** Each release now has `ferrite-vX-macos-universal.dmg`: open it and drag FERRITE to Applications. It runs on Intel and Apple Silicon, with the FERRITE icon, and the dedicated server and the FORGE MCP server are inside it (`FERRITE.app/Contents/MacOS/`).
- **Where the app keeps your files.** An app must not change itself, so the macOS app keeps its settings, maps, prefabs, music, screenshots and stats in `~/Library/Application Support/FERRITE`. The Windows, Linux and macOS archives still keep them beside the game.
- **Updating the app.** When a new version is out, the launcher's DOWNLOAD button opens the new disk image; replace FERRITE in Applications with it. The archives still update themselves in place.
- **The lobby chat stays in its column.** A long round's chat log (kill streaks and all) climbed out of the chat column and over the map and mode votes. The lobby now shows as many of the newest lines as fit beside the teams.

## Opening the app the first time

The app is signed ad hoc, not with an Apple Developer ID, so the first time macOS says it cannot check FERRITE. Open **System Settings > Privacy & Security**, choose **Open Anyway** next to FERRITE, and confirm. After that it opens like any other app.

## Compatibility

No network protocol change (still 21): v0.15.4 plays with v0.15 and v0.14 clients and servers.
