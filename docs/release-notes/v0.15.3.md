# FERRITE v0.15.3

Public servers, listed in the game, and a home at [playferrite.com](https://playferrite.com).

## Changes

- **Public servers in JOIN SERVER.** A new PUBLIC SERVERS list sits above the games on your network. It shows each server's name, map, mode, players and your ping, refreshed every two seconds; click one to join. Two run around the clock in North America: `na1.playferrite.com` and `na2.playferrite.com`.
- **The home screen counts them.** With no game on your network, JOIN SERVER says how many public servers are online.
- **The list lives on the website.** The game reads it from `https://playferrite.com/servers.json`, so servers can be added without a new release. If the site cannot be reached, NA1 and NA2 are listed anyway.
- **Servers answer a status query on their game port.** A dedicated server now tells the list how it is doing on UDP 27500 itself, so a public server needs no second port open, and LAN discovery (27499) can stay off. The query is bigger than the answer and replies are capped per tick, so a server cannot be used to flood someone else.

## Compatibility

No network protocol change (still 21): v0.15.3 plays with v0.15 and v0.14 clients and servers. A server older than v0.15.3 still shows in the list and can be joined, but without its map and player count.
