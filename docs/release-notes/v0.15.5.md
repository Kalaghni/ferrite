# FERRITE v0.15.5

Sniper rounds go through bodies: line them up and drop them all with one shot.

## Changes

- **Collateral damage for long rifles.** A Longrifle, Ranger or Hammerhead round now goes through up to 3 enemies standing in a line. It keeps 80% of its force through each body, so a Hammerhead body shot does 115, then 92, then 74, and headshots still double. Walls and cover still stop the round, teammates are still passed through harmlessly, and everyone the round hits is marked for your team.
- **COLLATERAL.** Two or more kills with one round is a collateral: +50 score for each extra kill, a chat line everyone sees ("NAME - COLLATERAL: 2 with one shot") and a banner for the shooter.
- Every other gun still stops at the first body it hits.

## Compatibility

No network protocol change (still 21): v0.15.5 plays with v0.15 and v0.14 clients and servers. The server decides hits, so collaterals happen on servers running v0.15.5; the shooter's banner needs a v0.15.5 client, and the chat line shows for everyone.
